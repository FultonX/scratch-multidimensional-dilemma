# Generated original assets

Files in `generated/` are deterministically extracted from the source SB3 by
`tools/extract_sb3.py`. Binary PNG and WAV files are supplied in the separate
`TheMultidirectionalDilemma-binary-assets.zip` so the Git commit stays text-only.
Extract it at the repository root. Do not hand-edit generated files; logical
metadata is in `data/asset_manifest.json`.
